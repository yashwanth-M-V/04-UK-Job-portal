# Job Postings Data Pipeline

This repository publishes active job openings using a simple data pipeline.
Expired postings are automatically removed based on deadlines.

## 🤝 Contributing (Beginner Friendly)

You don’t need to know Python to contribute.

- Found a job? Open an issue
- Approved? Add it to `docs/pending-jobs.md`
- Get a real GitHub contribution ✔️

See [CONTRIBUTING.md](CONTRIBUTING.md) for full steps.

🔄 Jobs refresh daily at 9:00 PM UTC via GitHub Actions
