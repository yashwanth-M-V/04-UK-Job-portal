## ✨ Features
- 🔄 **Automated Pipeline**: End-to-end extraction, transformation, and loading (ETL) of job data.
- 🔍 **Role Categorization**: Automatically groups jobs into categories (Data Engineer, Analytics Engineer, Data Architect, etc.) using regex pattern matching.
- 📅 **Date Filtering**: Users can filter listings by 'Today', 'Last 3 days', 'Last 7 days', or 'Last 14 days' directly on the UI.
- 📈 **Data Persistence**: Uses Supabase (PostgreSQL) for reliable job storage and versioning via Parquet files in object storage.
- 🎨 **Responsive UI**: A clean, modern HTML/Jinja2 interface for viewing and applying to roles.

## 🛠 Tech Stack
- **Languages**: Python, HTML
- **Data Processing**: Pandas, PyArrow, OpenPyXL
- **Database/Cloud**: Supabase (PostgreSQL), Supabase Storage
- **Scraping**: `python-jobspy`
- **Templating**: Jinja2

## ⚙️ Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/yashwanth-M-V/04-UK-Job-portal.git
   cd 04-UK-Job-portal
   ```
2. **Setup virtual environment**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
3. **Install dependencies**:
   The project uses `pyproject.toml`. Ensure you have Python 3.12+ installed.
   ```bash
   pip install -r requirements.txt # Or use your preferred package manager
   ```
4. **Environment Variables**:
   Create a `.env` file with the following keys:
   - `API_URL`: Your Supabase API URL
   - `SUPABASE_KEY`: Your Supabase Project Key
   - `CONNECTION_STRING`: Your PostgreSQL connection string
   - `SUPABASE_BUCKET_NAME`: Your storage bucket name

## 🚀 Usage
To run the pipeline and refresh the job portal:
```bash
python main.py
```
This command triggers the scraper, transforms the data into the 'Gold' dataset, updates the database, and re-renders the `index.html` file.

## 🧩 How It Works
1. **Scraping**: `src/scrape/job_scraping.py` pulls data from job sites.
2. **Transformation**: `src/transform/transform.py` filters relevant data and enforces schema requirements.
3. **Ingestion**: `src/ingest/ingest.py` pushes cleaned data into the Supabase database.
4. **Rendering**: `src/render/render.py` pulls data from the DB and uses `template/job_template.html` to generate the final static site.
